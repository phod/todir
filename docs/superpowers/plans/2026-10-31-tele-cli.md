# Tele CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `tele`, a Go directory-alias CLI with worktree-aware aliases, interactive pickers, and bash/zsh shell integration, per the design.

**Architecture:** One Go binary `tele`. A pure mode-resolver turns flags and positionals into a `Mode`; handlers in `internal/cli` act on a `store` (TOML aliases), `gitx` (git subprocess wrapper), `picker` (Bubble Tea), and `shellinit` (emits the `tele` shell function plus completions). The binary signals a `cd` to the wrapping shell function by writing the target path to the descriptor named in `TELE_CD_FD`, or to stdout when unset.

**Tech Stack:** Go 1.26, `github.com/spf13/cobra`, `github.com/BurntSushi/toml`, `github.com/charmbracelet/bubbletea`, `github.com/charmbracelet/bubbles` (textinput), `github.com/sahilm/fuzzy`, `golang.org/x/term`. Install each with `go get <module>@latest` the first time a task needs it.

**Spec:** `docs/superpowers/specs/2026-10-31-tele-cli-design.md`

## Global Constraints

- Module path placeholder `github.com/phod/tele`; the binary is `./cmd/tele`, installed as `tele`. One edit to rename later.
- Platforms: darwin and linux, amd64 and arm64. Shells: bash (function must load on 3.2) and zsh.
- Every error message is one line on stderr prefixed `tele: `. Exit codes: 0 ok, 1 runtime error, 2 usage error, 130 picker cancelled.
- Lists, `--init`, help, version go to stdout. Register/delete confirmations go to stderr. Navigation target goes to `TELE_CD_FD` when set, else stdout.
- Alias names match `^[A-Za-z0-9][A-Za-z0-9._-]*$`.
- Config file: `$XDG_CONFIG_HOME/tele/aliases.toml`, default `~/.config/tele/aliases.toml`; file 0600, dir 0700, atomic write.
- git is only invoked for worktree operations; plain operations must work with no git on PATH.
- Pickers render to stderr and require a TTY on stderr. `NO_COLOR` disables colour.
- Performance: plain `tele <alias>` under ~20 ms end to end.
- Commit after every task with a conventional-commit message.

## Review Focus

Inputs the spec implies but doesn't spell out, each pinned by a test in the owning task:

1. An alias name that looks like a flag or a path (`-x`, `foo/bar`) on register → usage error exit 2, not a stored alias (Task 5).
2. `-r` given a file or a nonexistent path → exit 1 with the path in the message, store untouched (Task 5).
3. A hand-edited worktree alias whose relative path escapes the repo root (`../x`, `/abs`) → refused, never a `cd` outside the top level (Task 7).
4. Bare `tele` or `-li` with an empty store → one-line hint, exit 1, picker never opens (Task 9).
5. `git worktree list --porcelain` output with a detached HEAD, a bare entry, or a `prunable`/`locked` line → parsed without error and listed sensibly (Task 6).
